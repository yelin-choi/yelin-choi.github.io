# 최예린 포트폴리오

HTML / CSS / JavaScript만 사용하는 반응형 정적 사이트입니다. 빌드나 패키지 설치 없이 GitHub Pages로 서빙할 수 있습니다.

- `index.html`: 홈, 주요 성과, 대표 프로젝트, 연락처
- `work.html`: 분야별 프로젝트 필터
- `experience.html`: 경력과 교육
- `project.html?id=1`: 프로젝트 상세 (1–6)
- `projects.js`: 프로젝트 문구와 정보
- `assets/profile.png`: 프로필 사진

로컬 미리보기: `python3 -m http.server 8000` 후 `http://localhost:8000` 접속.

GitHub에 푸시한 뒤 Settings → Pages → Deploy from a branch에서 사용 브랜치의 `/ (root)`를 선택합니다. `.nojekyll`을 포함했습니다.

첨부된 데스크톱·태블릿·모바일 이미지를 디자인 기준으로 사용했습니다. 공개 Framer 사이트에서 프로젝트 소개 문구와 LinkedIn 주소를 확인했습니다. 프로젝트 산출물은 참고 이미지와 같이 자리표시자로 남겼습니다. 상세 페이지는 제공된 경력 및 공개 소개 정보 범위의 개요입니다.
